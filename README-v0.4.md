# EnergizeCheck v0.4 - Asset Explorer and Diagnostic Intelligence

v0.4 turns the v0.3 calculation engine into an engineering decision-support workflow.

## Added
- Hierarchical Asset Explorer: Block -> Inverter -> MPPT -> String -> Module
- Asset-level engineering metrics and current rule findings
- Diagnostic knowledge base with possible causes and recommended investigation actions
- Persistent finding lifecycle: OPEN, ACKNOWLEDGED, UNDER INVESTIGATION, CORRECTIVE ACTION, READY FOR RETEST, CLOSED, REOPENED
- Finding-case audit history
- Project KPI dashboard with overall readiness, blockers, warnings, failed tests and open NCRs
- Readiness drill-down by discipline and block

Diagnostic recommendations are investigation guidance, not a substitute for approved engineering procedures, manufacturer instructions, project method statements, or applicable standards.
